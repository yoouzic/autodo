# 豆包桌面连接器配置

仅在豆包客户端提供自定义 STDIO 连接器时使用。打开「新建自定义连接器」，填写以下各项，将占位路径替换成自己电脑上的绝对路径。

| 字段 | 值 |
| --- | --- |
| 服务器名称 | `todo-dispatcher-doubao` |
| 传输类型 | `STDIO` |
| 命令 | Python 解释器的绝对路径，例如 `C:\Python314\python.exe` |
| 参数 1 | `-B` |
| 参数 2 | `<AuToDo 项目目录>\scripts\doubao-mcp-worker.py` |
| 参数 3 | `--root` |
| 参数 4 | `<AuToDo 项目目录>` |
| 环境变量 | 留空 |

四个参数分别填写。保存后在客户端确认连接器信任与授权。将 `doubao` 加入 `enabled_executors`，将 `doubao_transport` 设为 `mcp`，重启 AuToDo 服务。专用会话见 [桌面会话待命](desktop-worker-standby.md)。

## 会话等待与重载

豆包客户端单次工具调用有 60 秒上限。0.1.2 起，`wait_for_task` 每段最多等待 40 秒，返回 `idle_continue` 时应立即串行再调用同一工具；它是正常续等结果，不是错误。专用会话需要明确允许这种续等。遇到 `idle_timeout`、取消或错误则停止。

同一连接的闲置窗口默认最多 15 分钟，包含模型两次调用之间的间隔；段间须在 15 秒内续接，最多 24 段。派工台只在工具实际等待时显示就绪。窗口结束后，重新连接插件并启动专用会话；成功提交上一任务后，同一会话可继续开启下一等待窗口。

连接器显示 **运行失败** 时，进入 **插件·技能·伙伴 → 插件 → 管理 → todo-dispatcher-doubao**，点击条目或详情中的 **重新启动**。本机公开安装代码确认该按钮调用本地连接器重试流程；“启用连接器”开关只是可用状态更新，不能据此认定进程已经重建。命令、四项参数和原账号授权均不需要改动。
