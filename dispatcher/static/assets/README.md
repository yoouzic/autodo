# Paper texture and theme

`paper.webp` is the cotton-paper texture from SWU TIC, an independently authored project by the AuToDo maintainer. The original texture was generated with ChatGPT and converted to WebP at quality 88 without cropping, recoloring, or resampling. AuToDo displays it as a repeating 640 px tile with multiply blending.

The color palette draws on SWU TIC and YouziAuth. The AuToDo layout and interactions are implemented in this repository.
